Design Summary: Icon Standardization & Theme Consistency

Full design for review before we proceed to implementation.

1. Unified Icon — Three Overlapping Keys

App Icon

All platforms

  • Style: Overlapping / layered, center key taller and in front
  • Background: Near black (#1C1917), rounded square
  • Key colors: Lime #A3E635 (outer), #84CC16 (center), strokes #65A30D / #4D7C0F
  • Key holes: Match background color for transparency effect
  • Extension toolbar (16px): Keys only, no background square

2. Icon Deliverables Per Platform
