# @keykeykey/ui

Shared UI tokens and components for KeyKeyKey. Provides design consistency across all platforms.

## Exports

### `tokens`
Design tokens consumed by all apps:
- `colors` — primary, background, surface, text, border, and semantic colors (light/dark)
- `spacing` — consistent spacing scale (xs through 2xl)

## Development

```bash
# Run tests
pnpm test

# Run tests with coverage
pnpm test:coverage

# Build
pnpm build

# Watch mode
pnpm dev
```

## Usage

```typescript
import { colors, spacing } from '@keykeykey/ui/tokens';
```
